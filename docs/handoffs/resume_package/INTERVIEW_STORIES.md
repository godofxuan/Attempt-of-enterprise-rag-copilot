For every answer use:

```text
Situation -> Problem -> Hypothesis -> Experiment -> Result -> Decision
          -> Trade-off -> What I learned
```

Do not memorize only the result. Be ready to identify the evidence JSON, explain
why the metric is not answer accuracy, and state what remains unmeasured.
