# ESA 0.4.0 本地服务工作台

本轮0.3/0.4升级完成，定位为**本地单用户、合成TEST后端的可运行演示版**。应用代码冻结于 `b50d0f8a47d34e29d9706a2c4ef25db193ec0d26`；其后的交付提交仅更新说明。0.2.0保留为有效历史成果，旧说明见 [RELEASE_020](../history/RELEASE_020.md)。

## 用户能完成什么

- 独立RAG：导入MD/TXT/PDF/DOCX，批量建库、替换/停用/恢复文档；Fast问答与Deep分题检索、锚定阅读；打开对应版本原文及真实页/段。
- Service Agent：用户明确服务和操作上限，同一会话提问、自然补充、改期、选择设备、预览、确认和提交后查询。模型使用Ollama原生工具调用，真实观察进入下一步；不是程序预填工具次序。
- 借用：资格、实际排期和规格筛选，当前精确确认后生成唯一待审批单；本地服务台处理、预留、领用、归还，再在同一数据库申请。支持待审批撤回、领用后续借预览及用户允许的日期备选。
- 报修：空字段补问、自然描述、完整预览、确认生成待受理单，再处理、解决、关闭；明确动作可重新打开。
- 普通业务代码负责参数、权限、版本、当前预览、精确确认、事务和幂等读回。模型不能批准工单或代表用户确认；服务台由TEST操作者明确操作。

独立RAG和Agent都使用大模型，共用Library/KnowledgeService、检索与唯一答案发布器。FAISS是安装的开源库，向量索引由本机bge-m3对用户导入的文档生成，不是下载的别人知识库。上传制度用于解释，不会暗中修改SQLite业务规则。

## 启动与一条完整演示

完整安装命令见 [START](START.md) 和根README；在项目根目录：

```powershell
uv sync --locked --no-dev
uv run --no-sync esa init --sample --data-dir .private/esa-vnext
uv run --no-sync esa serve --data-dir .private/esa-vnext --port 8740
```

打开 http://127.0.0.1:8740/ 。当前开发环境也可用 `.venv\Scripts\python.exe -m app.cli serve --data-dir .private/esa-vnext --port 8740`。使用现有目录时无需再次init，不重置数据库。

1. 选择本机已安装的qwen3.5:9b、bge-m3。资料库导入“由当前业务规则生成”的TEST示例并建立索引。
2. 知识入口询问借用资格、期限；Deep比较借用与会议室时长及条件，打开来源。会议室仅有知识能力，没有预订事务。
3. 开始借用，用户明确“预览后确认提交”。自然提供未来日期、用途、内存偏好；同回合可询问政策。选择实际设备并继续，模型读取规则/库存/本人申请并准备预览。
4. 修改结束日期，核对新参数与新预览。旧确认失效；单独确认当前完整内容。提交回执为PENDING_APPROVAL，**不是已批准、已分配或已预留**。
5. 本地TEST服务台核对动作预览，分别确认批准、领用、归还。批准时才事务内创建日期预留；归还释放。原提交回执不变，当前业务状态另行展示。
6. 回到会话查询当前状态，再在同一数据库办理。报修同理：补字段→预览→确认→OPEN→处理→解决→关闭。

这些是用户演示步骤，不是注入给模型的动作序列。已存在未结申请时先读原单并处理，不能重建数据库绕过限制。一个DATA_DIR只启动一个实例。

## 实测、负结果与限制

- 本轮主库新增109次chat、71次embedding POST：查询66个文本/66次POST，索引12个文本/5次POST。包含失败/重试；原主库40chat/26embed保留，最终149chat/97embed。其他历史账本未清零；归属不明的历史全项目消耗仍UNKNOWN。准确行级账目见结果包COST与原始记录。
- 8个合成chunk冷构建约3.031秒，缓存重建1.016秒且0新增embedding，含轮询开销。独立wheel两次启动约3.063/2.812秒。未做全流程公平前后延迟对照，不宣称Agent整体更快。
- 初期Deep丢条件、请求包预算不符、错误属性的“不规定押金”回答运费等真实负结果全部保留。两种无收益否定规则方案已回退。最终有限正反例通过不证明任意问题完整性；语义判断仍由模型提出，宿主来源核验不是独立语义真值。
- 模型可能选错内容、输出不合契约或无法完成任务；系统保存已验证内容和具体错误，不保证任意自然语言理解。自由文本auto仍实验，本版默认引导式范围。
- 本机单用户、合成服务台，无真实企业IAM/多角色审批/外部系统；不用于生产。没有OCR；复杂文档、大库质量、其他模型完整旅程、Linux和双入口容器化本轮未验证。
- 程序测试覆盖续借、重开、冲突与权限反例，但这些变体没有全部新增实时模型轨迹，不扩大宣传。
- 原7个无关tracked修改和无关untracked工作保持原样，没有打进本轮提交或源码发行包。恢复活动资料需要备份整个DATA_DIR；源码发行包不含模型、索引或业务数据。
