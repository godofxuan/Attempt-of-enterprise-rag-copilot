# 企业知识库智能问答与权限检索系统

**技术栈：** Python / FastAPI / BGE-M3 / FAISS / SQLite FTS5 / LangGraph / MCP

面向企业制度、Wiki、工单、邮件和会议记录等资料，建设统一接入、检索与问答系统。员工通过自然语言提问后，系统仅在本人资料权限范围内查找证据，返回带原文出处的回答；证据不足或权限不满足时给出部分回答或拒答，便于核查结果来源。

- 打通文件校验、解析、分块、文档版本、索引构建与回滚流程，支持 BM25 与 BGE-M3 检索；资料更新后通过版本化快照和原子切换降低索引中断与旧版本误用风险。
- 将用户身份、组织/资料权限、检索内容安全检查和回答引用校验放在服务端统一执行，检索结果只有通过 ACL 与内容准入后才能进入问答过程，回答来源可定位到原文档与分块。
- 对问答执行设置工具范围、调用次数、超时和安全终态，并记录可校验的处理轨迹，便于复盘“查了什么资料、采用了哪些证据、为何回答或拒答”；LangGraph/MCP 仅作为内部编排与工具协议实现。
- 在 WixQA 200 道固定公开检索题上将 Recall@5 从 42.75% 提升至 66.42%、nDCG@5 从 32.15% 提升至 52.16%；在公共 EnterpriseRAG-Bench 上完成 511,962 条记录的单机索引构建，约 231 秒建库、峰值内存约 1.83 GiB。
