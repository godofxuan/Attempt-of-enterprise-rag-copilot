# ESA 0.6 本地预览版

当前是一个 Python/FastAPI 应用、一个固定 DATA_DIR 和随包发行的 React 界面。面向本地单用户与合成 TEST 服务台；不是企业生产或多人审批平台。0.4 结果保留于 [历史发布说明](../history/RELEASE_040.md)，不能充当新版本重新运行的成绩。

## 使用

完整解压 Windows x64 ZIP，双击 ESA.exe。首次明确选择旧工作区或新建；已有记录会复用实例并打开实际地址。模型不在包中，应用不自动下载模型，日常不运行 pip/uv，也不需要 Node 或系统 Python。缺模型时设置和历史仍可使用。

当前本机有效工作区与入口见 [STATUS](STATUS.md) 顶部。升级保留整个 DATA_DIR，包括 workspace.json、app.sqlite3、documents、indexes 和 cache。不要为了演示重新 init 既有目录。完整说明见 [START](START.md)，开发边界见 [CODE_MAP](CODE_MAP.md)。

## 产品分工

- 独立知识：Fast 检索/来源组织/生成/唯一发布；Deep 实际分题搜索、锚定阅读和汇总。MD/TXT/PDF/DOCX 原文和版本可打开，无 OCR。
- 引导式 Agent：用户明确借用或报修与操作上限，主模型通过原生工具选择读取、参数更新、资源选择和准备。实际工具观察进入下一次输入；不会预填工具顺序。
- 普通业务代码维护当前参数、完整预览、精确确认、事务、幂等和读回。PREVIEW_ONLY 永远不提交；PENDING_APPROVAL 不是批准、分配或预留。
- 本地 TEST 服务台：借用批准/预留、领用、续借、归还；报修处理、解决、关闭、重开。所有动作都有当前预览和明确确认。
- 唯一会话输入框、三个主入口、按需事项/来源抽屉。执行记录区分模型提出调用、实际工具结果和程序检索计划，不展示虚构思考过程。

模型一次结束不代表业务完成。有实际工具进展时，程序可以交付已保存的参数和知识；缺少真实预览就明确尚未生成，保留原任务并允许选择候选后继续。不采纳模型口头宣称的“已准备”“已批准”。完全没有动作的空正文仍触发有界协议纠错/失败。

## 一条演示

1. 助理选择已有资料库，询问借用条件并展开来源；需要比较时选 Deep。
2. 开始借用，明确操作上限；输入未来日期、用途及规格。模型查询真实规则、资格、库存和本人申请。
3. 可以同时改期和问制度；检查实际日期与有来源的回答。若尚未生成预览，选择真实候选再继续。
4. 查看当前完整预览，改期会使旧确认失效。仅对当前内容精确确认，产生唯一待审批单；重复确认读回相同 command_id。
5. 在合成服务台逐项预览/确认批准、领用、续借和归还。回到会话查看当前状态，原提交回执保持原日期。
6. 同库再创建报修，补设备、描述和影响程度，预览/确认后处理至关闭；需要时明确重开。

这是用户演示流程，不是注入模型的固定工具动作序列。

## 限制与同步

自由文本 auto 为历史实验，不是默认支持入口；不能保证任意自然语言或任意知识问题完整正确。尚未证明追平 main。没有企业 IAM、真实外部系统、可靠多人共享或 Linux/容器发行实测。IT 报修与借用的维修资格记录是不同来源，不自动联动。

没有新增生产审查器、多 Agent 或第二后端。FAISS 是现成开源组件，知识向量由本机模型对导入资料生成；本轮没有新建向量索引或下载模型。模型原始调用与私有数据库不进入公开源码。

本轮本地 feature 分支里程碑已提交；未找到适用的远端同步授权，未 push、未创建 PR、未合并 main。7 个既有无关 tracked 修改与其他未提交成果保留。
