# Enterprise RAG / Service Agent：vNext长期产品与自主实施方案

日期：2026-10-29。

## 直接怎么用

将本包交给能访问真实项目工作区的Codex，发送`CODEX_START.md`中的启动提示词。Codex负责将本包放到项目的`docs/esa-vnext/`，将`AGENTS.append.md`的相关约定合并进已有项目指令，再按`GOAL.md`连续推进。不要让用户手动复制几十段任务。

本包替代此前`ESA_R2_REVIEW_CODEX_20261029`和`ESA_PRODUCT_REDESIGN_20261029`的实施路线；旧审核中的事实、反例和有效修复仍可复用，不能同时执行三份相互冲突的架构安排。

这是一套设计与执行任务，不包含已修复的应用源码，不代表已运行用户本机模型或已同步GitHub。

## 最终要看到的产品
