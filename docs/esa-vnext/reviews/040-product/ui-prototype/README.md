# 界面交互原型

双击`index.html`可离线打开。无CDN、无网络请求、无需启动后端。

所有资料、设备、日期、状态与提交结果均为合成演示。它不读取本机文件、不调用模型、不产生真实申请，不是ESA 0.5正式前端。Codex应按组件化设计实现并接入真实API，不将此静态原型替换产品后宣布完成。

可以尝试：助理/我的事项/资料库/服务台/设置导航；查看来源、事项详情；修改示例日期；模拟确认；首次使用三步向导；新对话后回到示例会话；窄屏导航。

`desktop.png`、`mobile.png`和`first-launch.png`是本原型截图，不是当前ESA或修复后的运行证据。`CHECKS.json`记录合成原型的浏览器交互检查，不能并入产品测试数。
