# 新版教学资源接入：只更新资源，不清零学习

这是已有三项目教学体系中的ESA/RAG桥接资源，不是替代学习实验室。原来的EvalOps、EntityBridge、Hot100和其他题库不改动。

## 先定位真正的学习断点

教学Codex在当前可访问工作区读取CURRENT_BREAKPOINT、CURRENT_TEACHING_CODEX、LEARNING_PROGRESS、COURSE_INDEX和最近本人作答。文件名不同就使用现有等价入口，不为了对齐模板另建一整套控制文件。

2026-09-16的材料中曾有EvalOps预检课记录；它只是历史快照，不能被本包当成今天的ACTIVE。当前路径、题号、掌握度无法确定时记unknown，不设为0，不默认从第一节重教。

## 一次接入

将本包teaching放入现有资源的独立版本子目录。按ESA3命名空间注册题目与答案，id联结。与旧题同概念时挂别名/新版本说明，不删除旧ID和本人答案；重复资源不宣传为净新增题。

只更新现有课程索引的ESA资源入口、真实函数位置和旧版本描述。记录一个短回执：实际目录、当前断点、哪些旧课被补充、下一次具体资源、未改哪些状态。不需要为接入另建哈希计划或授权账本。

资源中所有新题的learner_state为UNASSESSED，仅表示本资源未记入学生表现。导入器遇到已有实际学习记录时，以原记录为准，不能覆盖。

## 当前实现与旧说法的桥接

| 旧课容易沿用的说法 | rc3教学表述 |
|---|---|
| 默认由LangGraph驱动全部业务 | 当前正式路径为ServiceAgent原生工具循环；历史LangGraph代码不等于当前入口 |
| 只做固定RAG问答 | 同一应用含知识、借用、报修及生命周期；按真实入口讲 |
| 用户确认后模型再决定是否提交 | 明确按钮可直接调用业务用例，事务与读回归普通代码 |
| 任务完成就本轮问题完成 | Task/Turn/Run/Ticket分别负责；有F1反例，不能背一个SUCCESS |
| 首页没有旧记录就是数据丢了 | 先分辨列表截断、详情查询、工作区关联与真正删除 |
| 有引用或测试通过等于回答全对 | 结构、业务、语义、用户掌握是不同对象 |

## 工程与课堂互不阻塞

源码修复后，开发Codex更新teaching/SOURCE_MAP的受影响锚点与LESSON_VERSION_NOTES。教学Codex先做一次按符号定位，不重新生成全部题库。

课堂不需要先跑完整个产品验收。已可工作的保存→选择→预览链可直接学习；F1/F2/F3作为明确标注的调试案例。真实模型缺失时先做标准库实验，记LAB_ONLY，不能冒称本人已跑通产品RAG。

不改简历、投递主台账、既有已做题；工程CI与老师演示不自动计为学生完成。
