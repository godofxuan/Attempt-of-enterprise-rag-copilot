# 六个独立机制实验

这些是本次新编的教学示例，不是当前项目补丁，不导入产品、不访问网络，不读取活动数据库。仅使用Python标准库。

| 文件 | 机制 | 对应课 |
|---|---|---|
| request_projection.py | 当前请求依赖与事项待办分离 | L05、L07 |
| rrf_demo.py | 按名次融合与确定性排序 | L03 |
| sqlite_store.py | 乐观更新、事务、提交幂等 | L02、L06 |
| history.py | 详情主键读取和游标列表 | L06、L08 |
| dates_preview.py | 半开日期区间与预览当前性 | L06、L07 |
| evidence_view.py | 模型证据与界面来源；引用存在不等于语义正确 | L04 |

运行任意文件看例子，或`python teaching/labs/run_all.py`执行24个独立教学检查。检查记录写本目录last_run.json，不改项目数据和学生状态。

题目后给完整参考实现，适合“先完整示范，再换一个输入由本人预测/实现”。不要求学生一次运行24项才算开课；每节选相关实验。默认例子用内存SQLite、固定合成数据和显式时钟，因此可重复。

教学例子没有实现生产并发控制、完整身份、索引器或Agent，不能移入项目当成熟替代。学生应回到本课源码锚点看正式实现。
