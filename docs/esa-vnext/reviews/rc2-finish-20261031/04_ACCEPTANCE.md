# 有限且有效的验收

这12类是用户旅程，不是只允许12条断言；保留已有有效测试，新增只对应本轮修改/回归。不是本次已运行成绩。复核成绩见evidence。

## 层次与频率
- 开发中：受影响Python测试、TS类型与当前组件/缓存操作测试。
- 每批完成：对应产品API（真实临时SQLite）与浏览器场景；只替换外部模型时清楚标记。
- 冻结候选：使用受支持Python和最终Windows发行包。选定真实模型运行正常问答/Deep/业务混合输入；不调研所有模型、不反复抽样凑通过。
- 只修改视觉tokens时不重复全部真实模型试验；影响生成或业务逻辑时才重新跑对应路径。

## 12类行为
| ID | 场景 | 必须看到/保存的结果 |
|---|---|---|
| A01 | 首次双击、重复双击、端口已占用、模型未连接 | 页面可开；同一实例/正确版本；历史与设置可用；不安装依赖 |
| A02 | 已有工作区升级、移动后定位、重启 | 不创建假空库；资料/任务仍在；新版本明确；原生Windows验证 |
| A03 | 保存成功后prepare缺设备 | 参数已保存且revision更新；自动展示选择；重试不再发送旧保存载荷 |
| A04 | 报修缺必填字段 | 正常待补充，不是故障；焦点指向字段；补齐后继续且不新增重复事项 |
| A05 | 正确设备选择→预览→双击提交 | 不经过多余模型判断；真实预览；一次明确确认；只一张单据；同回执 |
| A06 | 预览成功、解释失败→重试解释 | 已有预览保留；只补知识；无重复参数改写/提交；正确完成状态 |
| A07 | A/B会话切换、长历史搜索、停止、刷新 | 进度和停止归属正确；草稿保留；历史可查全；正常返回当前事项 |
| A08 | 文档批量上传、某文件失败、更新/停用、来源打开 | 状态准确；失败只影响对应文档；新查询使用正确范围；原引用可解释 |
| A09 | 真实Fast/Deep与追问、修改+提问 | 有效检索与引用仍在；关键条件不丢；不能拿静态答案代替；实验解释保持独立 |
| A10 | 同一工作区借用后半程与再次申请 | 批准/领用/续借/归还/查询可用，库存与票据一致，当前状态不同于旧回执 |
| A11 | 报修全周期 | 创建、处理、解决、关闭、重开使用真实本地业务API；不靠SQL脚本伪演示 |
| A12 | 1440/1024/390宽度、抽屉与键盘、中文输入 | 无遮挡/整页横向滚动；单输入；IME不误发送；焦点可返回；长内容可读 |

## 视觉比较只做一组
从实际产品采集桌面主会话、事项待补充/候选、预览/回执、资料库、设置、手机会话这6类代表状态。使用真实UI和合成业务数据。不是另造高保真静态原型，也不要求每一像素一致。
对同一tokens最多一轮整体修正；剩余非功能性偏好入backlog，不形成无限美化循环。

## 发布判断
P0：数据损坏/丢失、越范围写入、双击重复真实单据、无法恢复原工作区。
P1：正常主流程不能完成、保存/状态错误、无法补充或重试、关键操作不可达。
P2：非阻塞视觉不一致、次要文案、低频非关键便利性。
本轮修P0/P1和明确选入的P2。不能为了得到“零bug”承诺不断把愿望提成P1。

## 记录只保留一张结果表
每项：候选commit、环境/外部替身或真实模型、动作、结果、未完成原因。浏览器或Windows缺环境时标NOT_RUN，而不是pass；可以推feature分支和发布明确预发布候选，不可声称稳定发行已验收。
当前7项旧回归通过与5个独立场景不是全量成绩，也不与历史测试次数相加。
